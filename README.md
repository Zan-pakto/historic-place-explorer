# Local History Explorer Chatbot

A web-based chatbot that helps users discover historical information about any location worldwide. The chatbot uses Google's Gemini AI to provide comprehensive and engaging historical facts and stories about places.

## Features

- 🗺️ Search any location worldwide
- 💬 Interactive chat interface
- 🎨 Modern UI with Tailwind CSS
- 📱 Responsive design
- 🤖 Gemini AI integration for rich historical insights
- 💡 Quick suggestion chips for common queries

## Technologies Used

- HTML5
- JavaScript (ES6+)
- Tailwind CSS
- Axios for API requests
- Google Gemini API

## Setup

1. Clone this repository or download the files
2. Get a Google Gemini API key from https://makersuite.google.com/app/apikey
3. Replace the `geminiApiKey` in `app.js` with your API key
4. Open `index.html` in a modern web browser or use Live Server
5. Start chatting and discovering history!

## Usage

- Type any location name in the chat
- The chatbot will provide:
  - Detailed historical overview
  - Cultural significance
  - Key historical events
  - Notable landmarks
- You can also click on suggestion chips for quick queries
- The responses are formatted with clear sections and bullet points

## Example Queries

- "Tell me about Paris"
- "What's the history of New York City?"
- "Show me historical places in London"
- "What happened in Rome during ancient times?"
- "Tell me interesting facts about Tokyo"

## Running with Live Server

For the best experience, use Live Server to run the application:

1. Install Live Server globally: `npm install -g live-server`
2. Run Live Server in the project directory: `live-server`
3. The application will open in your default browser at http://127.0.0.1:8080

## Note

This project requires an internet connection to fetch data from the Gemini API.
